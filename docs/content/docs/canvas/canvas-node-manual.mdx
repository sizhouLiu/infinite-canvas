# Canvas Node Guide

## Text nodes

Text nodes store prompts, drafts, descriptions, and AI-generated text. Double-click the content or select **Edit Text** in the toolbar to edit it. The toolbar also controls text size.

Select **Edit** to open the prompt panel below the node:

- An empty node generates text into itself.
- Editing an existing node creates a connected result node to the right, preserving the original.
- Use `@` to reference connected images, text, video, or audio. Image references appear as thumbnails and are numbered automatically when sent to the model.
- The model selection applies only to the current node. Fetch or enter model names in global Settings first.

To generate an image from text, prepare the prompt and select **Generate Image**. Infinite Canvas creates and connects a generation configuration node, starts generation, and lets you adjust the model, resolution (`1k` / `2k` / `4k` / auto), aspect ratio, and output count before retrying.

## Image nodes

- Generating from an empty image node writes the first result into that node.
- A single result replaces the current empty node; multiple results use it as the primary node and add result nodes to the right.
- A populated image node is reused as a reference image.
- Generated nodes record the prompt, generation type, model, size, quality, count, and references in `metadata`.
- A retry stops with a clear warning if required references can no longer be restored.
- A Tripo channel also serves image generation, with its own model list (the `seedream`, `banana`, and `chat_image` families). Each family accepts different size arguments, so the resolution and aspect ratio you pick are mapped to whatever that model takes and snapped to its nearest accepted tier. Tripo has no count parameter, so asking for several images issues several tasks, each billed separately.

## Video nodes

Create a video node from the toolbar or upload a local video. Video nodes use the native player. An empty video node can generate into itself, while generation started from text, images, or configuration nodes creates a connected video node. Generation-config video mode reads upstream text as the prompt, images as reference images, videos as reference videos, and audio as reference audio. Built-in OpenAI and Gemini requests use the same fields as the insertable call-script templates. Custom video request scripts can read those files from the `videos` and `audios` variables.

Video settings use `480p` / `720p` / `1080p` with `1:1`, `3:4`, `4:3`, `16:9`, `9:16`, `21:9`, or auto, and compute width and height from that pair. Duration is a 4–30 second slider. They also include first-and-last-frame mode and general-reference mode. With first-and-last-frame mode, one image is sent as the first frame and two images as first and last frames. More than two images are sent as general references even if first-and-last-frame mode is selected. Built-in requests and request scripts both use the resolved `frames` or `reference` mode.

The OpenAI-compatible flow uses `POST /v1/videos`, `GET /v1/videos/{id}`, and `GET /v1/videos/{id}/content`, sending `first_frame` / `last_frame` or `image[]` plus optional `video[]` / `audio[]`. Gemini-format channels use `models/{model}:predictLongRunning` and poll the operation, sending `image` / `lastFrame` or `referenceImages`. After a remote task is created, its ID is stored on the video node so a page refresh can keep polling, or you can click **Get task status**. Polling stops when the video is ready, the task fails, or the status request errors.

## 3D nodes

Add a Tripo channel in Settings (apiFormat "Tripo") and enable the local proxy first: Tripo's `/v3` endpoints send no CORS headers, so the browser cannot reach them directly. Tripo runs two independent regions, China (`openapi.tripo3d.com`) and global (`openapi.tripo3d.ai`); a channel with apiFormat "Tripo" shows a region picker, and because the two are separate accounts each channel needs its own API key.

Create a 3D node from the toolbar or the connection menu. The node renders the glb in a viewer you can rotate by dragging and zoom by scrolling; the interaction toggle switches between rotating the model and moving the node. A prompt on an empty 3D node runs text-to-3D, while an upstream image node is uploaded to Tripo first and runs image-to-3D.

3D settings cover texture, PBR material, texture quality (standard/detailed/extreme), and a face limit. An empty face limit means auto; allowed ranges differ per model, and an out-of-range value surfaces Tripo's own message.

Tripo generation is asynchronous: the task ID is stored on the node so a page refresh keeps polling until the model is ready, the task fails, or the status request errors. Measured timings are about 3 minutes and 10–30 credits for text-to-3D, and about 80 seconds and 20 credits for image-to-3D. On success the glb and its preview image are downloaded into browser storage before being displayed, because Tripo's signed URLs expire within a day. Hover or right-click a populated 3D node to download the file, choose **Import to Blender** to send the stored model to a local Blender that has the Tripo Bridge addon enabled (`ws://127.0.0.1:60600`), or **Open in Bambu Studio** to launch Studio with `bambustudio://open?file=` pointing at a 3MF. Select several 3D nodes (or a group that contains them) to run either action together. Blender import needs the canvas on `http://localhost` — a hosted HTTPS page cannot open that local socket. 3MF is not sent to Blender; convert to a supported format first if that is the only copy. Opening Bambu Studio converts the node to 3MF automatically through the same 3D-ops conversion (this spends credits) and writes the result back before launching Studio. Studio fetches an HTTP URL itself, so a still-valid Tripo conversion URL is used when present, otherwise Canvas Agent hosts the local file briefly.

3D operations act on a node that already holds a model. Hover it and open **3D ops**: retexture, auto-rig, apply animation, decimate, segment parts, complete mesh, and convert format. Each opens one shared dialog whose fields differ per operation, and each produces a new 3D node to the right — except conversion, which writes back to the same node.

Two operations only chain off work done in this canvas: **apply animation** needs a node you rigged here, and **complete mesh** needs one you segmented here. Tripo accepts only the upstream task id for those two and rejects an uploaded file, so they are greyed out elsewhere with an explanation. Every other operation works on any 3D node, re-uploading the stored model when the original task id is gone. Auto-rig first runs Tripo's free riggability check and stops with a readable message, spending no credits, when a model cannot be rigged.

Format conversion emits FBX, GLTF, USDZ, OBJ, STL, or 3MF (not GLB, which Tripo rejects — it is already the native output). These cannot be shown in the glb viewer, so the artifact stays on the source node and the 3D ops menu gains a download entry for it. The converted file is stored locally and survives reopening the project.

Multiview: connecting 2–4 image nodes to a 3D generation runs multiview-to-3D rather than using only the first image. The front view is required, so the first connected image becomes the front unless it already carries an angle from a multiview run; more than four images warns instead of dropping the extras silently. An image node's **Multiview** tool (off by default, since it spends credits) turns one image into four view nodes in a grid, and running it again on one of those opens an editor where filling in only some views changes just those.

## Group nodes

Group nodes collect several nodes so you can move them together and reference their contents in one connection.

- After box-selecting or Shift/Ctrl/Cmd-clicking multiple nodes, a rounded dashed bound wraps the selection and **Group** appears above it.
- Click **Group** or press `Ctrl / Cmd` + `G` to wrap the selection in a group node without moving the contents.
- With a group selected, use **Ungroup** in the toolbar or context menu, or press `Ctrl / Cmd` + `Shift` + `G`.
- You can also create an empty group from the toolbar and drag nodes into it; dragging a node out removes it from the group.
- Connecting a group to a generation node includes every populated image, video, audio, text, and reference-capable extension node inside it.

## Recommended workflow

1. Create a text node with the initial idea.
2. Ask AI to refine the prompt in the panel below it.
3. Compare the connected rewritten node with the original.
4. Select **Generate Image** on the chosen text node.
5. Adjust parameters or regenerate from the generated configuration node.
